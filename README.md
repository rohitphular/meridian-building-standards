# Meridian Building Standards

Shared development conventions, design guidance, document templates and delivery process for Meridian projects. Consume this repository as the `building-standards/` Git submodule.

- [Coding and design standards](documents/standards/)
- [Document templates](documents/templates/)
- [Development delivery process](documents/process/README.md)
- [Reusable task prompts](LLM-INSTRUCTIONS.md)

Follow the standards relevant to the consuming project’s technology and domain. The delivery process documents retain the market-analytics examples and rules from Meridian Convex; their scope is documented in the process README.

Commit and push shared changes in this repository before committing the updated submodule pointer in consuming projects.
